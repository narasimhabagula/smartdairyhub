# Smart Dairy Hub

Create a Smart Dairy Management Web App.

Include:

1. Milk rate calculator based on FAT & SNF

2. Buy and sell cows and buffaloes

3. Veterinary doctor contact list

4. Government subsidy and loan information

5. Farmer login and dashboard

Use clean modern UI and responsive design.
